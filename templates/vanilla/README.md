## Protocol Description

This protocol is the same as the original docking protocol as of 9/1/2025. 

Except for a few things. 

(1) It uses 100 cycles in high res docker, repacking all residues in selected movemap after every 3
(2) uses 200 nstructs
(3) No NSL conformers, only rotable bonds for NSL via -ignore_ligand_chi true
